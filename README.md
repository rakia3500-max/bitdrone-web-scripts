# bitdrone-web-scripts

빛드론(카페24)·드론박스(고도몰) 손님 화면에 거는 자바스크립트만 두는 저장소입니다.
jsDelivr로 내줍니다: `https://cdn.jsdelivr.net/gh/rakia3500-max/bitdrone-web-scripts@<커밋>/<경로>`

- 몰에는 꼭 **커밋 고정 주소**(@커밋 40자리)를 겁니다. 브랜치 주소(@main)는 캐시가 길어 바로 안 바뀝니다.
- **XML·사진·엑셀 같은 큰 파일은 넣지 않습니다.** jsDelivr는 저장소가 50MB를 넘으면 새 커밋을 못 내줍니다(2026-11-16 nshopping-manager에서 막힘 → 이 저장소로 옮김).

| 폴더 | 내용 |
|---|---|
| `bitdrone_popup/` | 빛드론 전용 (카페24 스크립트 태그) |
| `dronebox_popup/` | 드론박스 전용 (고도몰 외부 스크립트) |
| `web_scripts/` | 두 몰 공용 |
